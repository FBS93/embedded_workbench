#define EDF_HSM_EMPTY_SIGNAL   ((EDF_event_signal_t)0U)

Internal framework reserved signals for HSM management.

The order and numeric values of these signals are important and tightly coupled to the HSM implementation.

Forces a state handler to return its superstate.

This signal must never be handled explicitly. It always falls into the default case of the state switch and returns EDF_HSM_RET_SUPER(super).

typedef EDF_hsm_stateReturn_t(* EDF_hsm_stateHandler_t) (void *me, const EDF_event_t *e)

State handler function type for EDF HSM.

Note
The parameter me is void* to support C-style "inheritance": internally in the EDF library it is treated as EDF_hsm_t, while the user can implement state handlers using their specific AO type. The user AO's first member shall be EDF_hsm_t. This allows state handlers to access the full AO structure while keeping the EDF HSM implementation generic. When the EDF library calls the state handler of the user's AO HSM, an implicit cast from EDF_hsm_t* to the user AO type is performed.
Parameters
[in]mePointer to the HSM instance of the active object currently dispatching the event.
[in]ePointer to the event being dispatched.
Returns
EDF_hsm_stateReturn_t value indicating how the event was handled.

enum EDF_hsm_stateReturn_t

Internal return codes from state/action handlers.

Note
For EDF library internal use only. Users must use the public macros:
  • EDF_HSM_RET_HANDLED
  • EDF_HSM_RET_UNHANDLED
  • EDF_HSM_RET_SUPER
  • EDF_HSM_RET_TRAN
Enumerator
RET_HANDLED 

Event handled.

RET_UNHANDLED 

Event not handled, propagate to superstate if any, otherwise discard (top state).

RET_SUPER 

Explicit request to propagate event to superstate.

RET_TRANSITION 

Transition taken.

RET_IGNORED 

Reserved, used only in top state.
