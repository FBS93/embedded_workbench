◆ EVENT_BUFF_SIZE

#define EVENT_BUFF_SIZE   50U

Size of timeMgr event buffer.

The buffer must be large enough to hold the maximum number of consecutive posted events in the worst-case scenario without preemption. This ensures the test can also be used in non-preemptive core/port configurations.
