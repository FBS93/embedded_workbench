EBF_WEAK uint8_t EBF_utils_log2 ( uint8_t  byte)

Returns the position of the most significant set bit in a byte.

Returns the 1-based index of the most significant bit set in the input byte. If byte is fully clear, the function returns 0.

The default weak implementation is software-only (lookup table + shifts). On cores/ports that provide a hardware-specific instruction (e.g., CLZ in ARM), this function can be overridden for improved performance.

[in]byteinput byte.
