If the active object has no event queue, it can only retain one event at a time; subsequent events will be lost.
Parameters

[in]prioPriority of the active object.

[in]q_lenLength of the event queue. 0 if no queue.
[in]stack_storagePointer to the stack storage.
[in]stack_sizeSize of the stack storage.
[in]eEvent passed to the AO’s HSM initial state. NULL if not used. If NULL is provided, the AO initial state implementation shall not dereference or rely on this parameter.

EDF_activeObject_t *  next 
)

User-specific context switch callback.

Called whenever EDF switches execution between two active objects. The framework provides a dummy weak implementation, can be overridden by the application (e.g., to trace or profile scheduling, apply memory protection techniques, etc.).

Parameters
[in]prevPointer to the previously running active object (can be NULL).
[in]nextPointer to the newly scheduled active object.

◆ EDF_onIdle()

EBF_WEAK void EDF_onIdle ( void  )

User-specific idle callback.

Called whenever EDF have no active objects are ready to run. The framework provides a dummy weak implementation, can be overridden by the application.

Note
In non-preemptive ports, the idle task can delay the execution of the next ready active object.
