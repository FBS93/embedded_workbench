EDF_activeObject_t* EDF_framework_t::ao_registry[EDF_MAX_ACTIVE_OBJECT+1U]

Active objects registry, indexed by their priority.

Index 0 is unused; valid entries are 1 ... EDF_MAX_ACTIVE_OBJECT.

Note
The framework does not support unregistering; entries shall be only modified to add new active objects, never removed or replaced.

EDF_timeEventRegistry_t EDF_framework_t::te_registry[EDF_MAX_TICK_RATE]

Registry of time events for all tick rates.

Each index of this array corresponds to a specific tick rate. The user is responsible for calling EDF_timeEvent_tick() with the corresponding tick_rate index at the correct periodicity to represent the desired tick rate.
