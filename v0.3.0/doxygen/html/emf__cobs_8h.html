bool EMF_cobs_decode ( const uint8_t *  buff_in,
uint16_t  len_in,
uint8_t *  buff_out,
uint16_t *  len_out 
)

Decodes a COBS‑encoded buffer.

Note
Decoding stops when a EMF_COBS_PACKET_DELIMITER is encountered, or when len_in bytes have been processed.
The minimum size required for the buff_out size is: len_in - 2 bytes. This is because, in the best case, COBS encoding only adds one byte for the length code and one byte for the final EMF_COBS_PACKET_DELIMITER.
The input and output buffers must not overlap.
Parameters
[in]buff_inPointer to the COBS‑encoded input buffer.
[in]len_inLength of the input buffer, in bytes.
[out]buff_outPointer to the buffer to receive decoded data.
[out]len_outPointer to a variable that will be set to the decoded length.
Returns
true if a COBS packet delimiter (EMF_COBS_PACKET_DELIMITER) was found, so the output is valid. false otherwise.

COBS encode data to buffer.

Note
The output includes a trailing EMF_COBS_PACKET_DELIMITER.
The input and output buffers must not overlap.
Parameters
[in]buff_inPointer to input data to encode
[in]len_inNumber of bytes to encode
[out]buff_outPointer to encoded output buffer. The output buffer must be at least len_in + (len_in / EMF_COBS_BLOCK_MAX) + 2 bytes to accommodate worst-case COBS expansion.
[out]len_outPointer to a variable that will be set to the encoded length.
