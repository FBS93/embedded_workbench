Definition emf_print.h:95

Safe variadic print macro using EMF_print.

If no arguments are passed, it calls EMF_print with NULL. Otherwise, it builds a local array of arguments and passes them.

Todo:

Limit of 8 arguments is imposed by EMF_PRINT_NARG.
