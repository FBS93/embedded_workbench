EBF_WEAK void EBF_setStdinListener ( EBF_stdin_t  listener)

Registers a callback to receive standard input data.

Note
Defined as weak by default, allowing a custom implementation to override it.
Depending on the stdin implementation, the listener may be called from an ISR context when input data is received. If so, the listener implementation shall be treated as ISR code.
Parameters
[in]listenerFunction to be called with incoming data.

EBF_WEAK bool EBF_stdoutWrite ( const uint8_t *  data,
uint16_t  len 
)

Sends data to the standard output.

Note
Defined as weak by default, allowing a custom implementation to override it.
Since standard output may be a shared resource, all implementations shall be protected using EBF_CRITICAL_SECTION_ENTRY() and EBF_CRITICAL_SECTION_EXIT(). Therefore, Calling EBF_stdoutWrite() from an active EBF critical section violates the contract, as nested critical sections are not supported.
Supported message length is implementation dependent.
A false return value indicates that the data cannot be serialized and shall be handled explicitly by the caller, preferably using EAF asserts. Silently discarding the data is highly discouraged.
Parameters
[in]dataPointer to data to be sent.
[in]lenLength of the data in bytes.
Returns
true if all data was accepted for transmission; false otherwise.
