uint8_t EDF_core_schedule ( void  )

Determine the next active object eligible for execution.

Evaluates the current set of ready active objects and selects the highest-priority one that can preempt the currently running context, considering both the scheduler lock and preemption threshold.

Note
This function shall be called within a critical section.

Evaluates scheduling after an active object completes execution.

Determines if another active object should be activated based on current priorities and preemption thresholds, following the completion of the given active object's event processing.
