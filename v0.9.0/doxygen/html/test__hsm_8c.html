void EDFTest_onInit ( void  )

Init callback.

This function is defined as weak within the EDF Test framework, providing a default implementation in case the user does not define a specific behavior.

Note
All user software shall be initialized in this function, but EDF_run() must NOT be called, as control must return to the EDF test framework.
