)

Initializes a pool.

Note
Proper memory alignment of the pool storage is required to ensure safe pointer access. As described in free_list, the first bytes of each block store a pointer to the next free block; if the storage is not properly aligned, this may lead to undefined behavior or hardware faults on some architectures. It is recommended to use EMF_UTILS_MEM_ALIGNED_SLOT or an equivalent alignment-safe definition. This not only guarantees correct pointer alignment, but also ensures that the computed number of blocks matches the ratio of pool_size to block_size as intended.
Todo:
Currently, pools must be initialized in ascending block size order. Future implementations shall allow pools to be initialized in any order.
Parameters
[in]pool_storagePointer to the storage for the pool.
[in]pool_sizeTotal size of pool_storage in bytes.
[in]block_sizeSize of each block of the pool in bytes.

Dynamic range check. Only needed when EDF_pool_blockCnt_t is 8 or 16 bits; for 32-bit, n_total always fits.
