◆ ACTIVE_OBJECT_PRIO_TO_SIGNAL

#define ACTIVE_OBJECT_PRIO_TO_SIGNAL (   prio)     ((activeObject_eventSignal_t)(S1 + ((prio) - 2U)))

Deterministic mapping between active object priority and subscribed signal.

Each active object (except the last) subscribes to exactly one signal. The relationship is defined such that active object priority prio (starting from 2) maps to signal S1 + (prio - 2). The last active object subscribes to all signals.
