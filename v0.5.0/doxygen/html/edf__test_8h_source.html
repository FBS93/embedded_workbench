1/*******************************************************************************
2 * @brief Event driven test framework.
3 *
4 * Provides a lightweight and self-contained test mechanism tailored for
5 * Event Driven Framework (EDF). Tests run inside the actual EDF loop by using
6 * a dedicated active object created at the lowest priority, ensuring
7 * minimal interference with normal application behavior. This enables the
8 * execution of test stimuli and validations under real runtime conditions,
9 * while avoiding the intrusive main control flow of traditional test
10 * frameworks or log-driven validation approaches that rely on parallel
11 * executables.
