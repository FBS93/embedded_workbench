Dispatches a reserved HSM event to the given state handler.

Note
The caller shall ensure that state is a valid state handler.
Parameters
statePointer to the state handler function.
sigReserved signal to dispatch. Must be one of the following: EDF_HSM_EMPTY_SIGNAL, EDF_HSM_ENTRY_SIGNAL, EDF_HSM_EXIT_SIGNAL or EDF_HSM_INIT_SIGNAL.
