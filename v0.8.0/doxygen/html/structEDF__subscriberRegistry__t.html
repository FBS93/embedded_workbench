EDF_activeObject_bitmask_t* EDF_subscriberRegistry_t::list

Subscriber list, one entry per user event signal defined.

Each entry corresponds to a signal event (index == signal value) and stores the bitmask of active objects subscribed to that signal, indexed by their priority.
