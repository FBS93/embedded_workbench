const char *  fmt,
const uintptr_t *  args 
)

Logs a formatted message with arguments.

Function used by the EMF_LOG_... macros.

The prefix and formatted message are written atomically as one EMF_print message and follow its size and error handling.

Note
This function shall not be called from an active EBF critical section. See emf_stdout_critical_section_precondition.
Parameters
[in]log_levelLogging level of the message.
[in]fmtNull-terminated format string.
[in]argsPointer to array of arguments, or NULL.
