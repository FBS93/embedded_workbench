Todo:
Optional hard real-time optimization.

mlockall(MCL_CURRENT | MCL_FUTURE) locks all current and future memory pages of this process into RAM, preventing them from being swapped to disk. This can eliminate unpredictable page faults and improve timing determinism in hard real-time systems.

Considerations before enabling:

  • Requires root privileges or CAP_IPC_LOCK capability.
  • Limited by the RLIMIT_MEMLOCK resource limit (ulimit -l).
  • May consume significant RAM and reduce overall system flexibility.
  • Not strictly necessary for soft real-time applications.

If enabled, handle errors carefully: failure to lock memory does not necessarily mean the application cannot run, but timing may degrade. Use only if strict timing guarantees are required and the platform environment supports it.

Example code:

#include <sys/mman.h> // for mlockall()
if (mlockall(MCL_CURRENT | MCL_FUTURE) != 0) {
perror("mlockall failed");
// optional: decide if you want to exit or continue without locked memory
}

User-specific context switch callback.

Called whenever EDF switches execution between two active objects. The framework provides a dummy weak implementation, can be overridden by the application (e.g., to trace or profile scheduling, apply memory protection techniques, etc.).

Parameters
[in]prevPointer to the previously running active object (can be NULL).
[in]nextPointer to the newly scheduled active object.

◆ EDF_onIdle()

void EDF_onIdle ( void  )

User-specific idle callback.

Called whenever EDF have no active objects are ready to run. The framework provides a dummy weak implementation, can be overridden by the application.

Note
In non-preemptive ports, the idle task can delay the execution of the next ready active object.

void EDF_stop ( void  )

Stops the EDF framework.

Calling this function terminates the main EDF thread, which causes all Active Object threads to end abruptly. The user is responsible for invoking EDF_stop() only when the AO states are safe for an immediate shutdown.
