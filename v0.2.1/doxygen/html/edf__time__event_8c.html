void EDF_timeEvent_tick ( uint8_t  tick_rate)

Processes time events for a given tick rate.

Note
This function shall be called periodically at the frequency corresponding to the given tick rate.
Parameters
[in]tick_rateTick rate index.
Note
The implementation uses a pointer-to-pointer (EDF_timeEvent_t **te_link) to avoid special-casing the first element of the time event registry:
  • At the start, te_link = &registry->armed_head.
  • As we traverse the armed time events list, te_link is updated to point to the next field of the current node: te_link = &te->next, where te = *te_link.
  • Removing a node is always *te_link = te->next; (works for both the first node and all subsequent nodes).

Attaching freshly armed time events (registry->new_head) is also unified:

  • When *te_link == NULL and registry->new_head != NULL, simply do *te_link = registry->new_head; (this attaches the new time events list either at the beginning of registry->armed_head or after its last node).

This way the same code handles head removal, internal removals and attaching new time events without branching on special cases.

Attach new time events to armed list; Updates registry->armed_head or registry->armed_head[last].next depending on the current te_link.
