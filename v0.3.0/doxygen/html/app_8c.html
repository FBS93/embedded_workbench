◆ EDF_onContextSwitch()

void EDF_onContextSwitch ( EDF_activeObject_t *  prev,
EDF_activeObject_t *  next 
)

User-specific context switch callback.

Called whenever EDF switches execution between two active objects. The framework provides a dummy weak implementation, can be overridden by the application (e.g., to trace or profile scheduling, apply memory protection techniques, etc.).

Parameters
[in]prevPointer to the previously running active object (can be NULL).
[in]nextPointer to the newly scheduled active object.
